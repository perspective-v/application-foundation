# Fumadocs local preview

This site previews the repository's existing MDX files directly. Edit `../index.mdx` or a page under `../docs/`; the local watcher reloads the preview.

```powershell
npm ci
npm run dev
```

Use Node.js 22 or newer. Open the URL printed in the terminal (normally [http://127.0.0.1:3000](http://127.0.0.1:3000)); Next.js chooses another free port if needed.
