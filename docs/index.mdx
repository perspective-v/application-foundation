- [Primitives](primitives): shared entity and model contracts.
- [Common](common): configuration, identity, mapping, paging, and utilities.
- [Entity Framework](entity-framework): EF Core extensions and repositories.
- [Web](web): MVC, REST, and S3 storage helpers.
