`PerspectiveV.Common` targets `net10.0`, enables nullable annotations and implicit usings, references the `Microsoft.AspNetCore.App` shared framework, and project-references `PerspectiveV.Primitives`. The public source is grouped under the namespaces and folders below. Option objects are plain data holders unless a method is listed; declaring an option does not configure middleware or register a service by itself.

All source paths below are relative to the repository root. Nullable annotations and optional parameters follow the C# declarations. This page documents the implementation in this repository, including current behavior that may be surprising.

Processor allowlists and entity expression properties must stay aligned. EF Core translation of `ToLower`, string containment, and dynamically built expressions depends on the configured provider.
