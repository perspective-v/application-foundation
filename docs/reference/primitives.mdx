`PerspectiveV.Primitives` defines the shared contracts and simple base types used by the other libraries. The project targets `net10.0`; its project file has no project references or explicit NuGet package references. The types are in the `PerspectiveV.Primitives.Types.Interfaces`, `PerspectiveV.Primitives.Types.Entities`, and `PerspectiveV.Primitives.Types.Models` namespaces.

All properties documented here are public and mutable (`get; set;`). The library declares no explicit constructors or methods on these types. Its public classes therefore use the compiler-provided parameterless constructors. Contracts and marker properties describe data shape; they do not validate values, populate audit metadata, filter queries, or implement persistence behavior by themselves.

`Entity.Id` is a non-nullable `Guid`; `Entity<IdType>.Id` has the declared type `IdType`. The generic identifier's actual value and generation behavior depend on its type and the consuming persistence provider. The key attributes request identity generation through data annotations; this package does not generate identifiers itself.

The inheritance chain composes concerns as follows: named variants add `Name`; soft-deletable variants add `IsDeleted`; auditable variants add the four audit properties. `AuditableSoftDeletableEntity` extends `SoftDeletableEntity` directly and declares audit properties itself; the named audit/soft-delete variant extends that class and adds `Name`.

## Selecting a base

Choose an entity base when defining a persistence entity and a model base when defining an application-facing data object. Use a generic variant when the identifier type is not the non-generic `Guid` convention. Select only the concerns a type needs:

| Required shape | Entity | Model |
| --- | --- | --- |
| Identifier only | `Entity<TId>` | `Model<TId>` |
| Name | `NamedEntity<TId>` | `NamedModel<TId>` |
| Audit fields | `AuditableEntity<TId>` | `AuditableModel<TId>` |
| Soft-delete flag | `SoftDeletableEntity<TId>` | `SoftDeletableModel<TId>` |
| Audit and name | `AuditableNamedEntity<TId>` | `AuditableNamedModel<TId>` |
| Audit and soft delete | `AuditableSoftDeletableEntity<TId>` | `AuditableSoftDeletableModel<TId>` |
| Name and soft delete | `SoftDeletableNamedEntity<TId>` | `SoftDeletableNamedModel<TId>` |
| Audit, name, and soft delete | `AuditableSoftDeletableNamedEntity<TId>` | `AuditableSoftDeletableNamedModel<TId>` |

Use the non-generic class name from the same family when the default `Guid` entity identifier or nullable `Guid` model identifier is appropriate. Implement `IAppClient` separately when a type needs `AppClientId`; no provided entity or model base implements it.
