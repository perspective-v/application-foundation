Application Foundation is a set of four NuGet libraries for common application types, cross-cutting helpers, Entity Framework Core data access, and ASP.NET Core web features.

## Package set

| Package | Purpose |
| --- | --- |
| `PerspectiveV.Primitives` | Entity and model contracts and base types. |
| `PerspectiveV.Common` | Shared configuration, identity, mapping, paging, helpers, logging, and mailing. |
| `PerspectiveV.EntityFramework` | EF Core repository contracts, implementations, and extensions. |
| `PerspectiveV.Web` | MVC and REST base classes, response handling, and S3 storage. |

The projects target `net10.0`. Package versions and dependencies are maintained in each project file. The packages are currently prerelease versions; see [getting started](/docs/getting-started) before installing them.
